# NutriPlan

A nutrition planning app built with React + Vite + Supabase.

## Setup

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this repo to GitHub
2. Connect to Vercel
3. Set build command: `npm run build`
4. Set output directory: `dist`

## Notes
- Supabase URL and key are in `src/App.jsx`
- Move them to `.env` before production
